# 에셋 목록

포트폴리오에 쓸 그림과 한 줄 설명, 어느 자리에 맞는지를 적었다. 경로는 모두 `docs/screenshots/` 아래다. 스크린숏은 전부 실제 앱에 예시 데이터를 넣어 그린 것이라 개인 정보가 없다.

자리는 네 가지로 나눴다. README(저장소 첫 화면), 한 장(포트폴리오 한 장 요약), 사례 글(문제 해결과 디자인 과정), 링크 카드(이력서나 메신저에 링크를 붙였을 때 뜨는 그림).

## 다시 그리는 방법

Mac은 `cd mac && ./scripts/render-design.sh [ko|en|nl] [night]`로 `mac/docs/design/`에, Windows는 `cd windows && npm run snapshot [-- lang=en]`으로 `windows/snapshots/`에 그린다. 두 폴더는 저장소에 올리지 않는다.

## 만들면 좋을 GIF

움직임을 봐야 하는 기능은 5–10초 GIF가 잘 읽힌다. 입력 줄 GIF(`docs/readme/`)와 소개 페이지의 메모 서랍 영상(`site/assets/drawer-*.mp4`)은 만들었고, 나머지는 아직이다.

| 아이디어 | 보여 줄 것 | 만드는 법 |
| --- | --- | --- |
| 하루 일정표 | `하루 전체 ›` → 일정표가 펼쳐짐 → 블록이 마우스를 따라오고 놓으면 15분 칸에 → 아래 끝을 끌어 늘리기 | 화면 녹화 6–8초 |
| 체크 | 네모가 세이지색으로 톡 커지고 연필 선이 그어짐 | 2–3초 반복 GIF |
| 고양이가 알림을 가져옴 | 화면 오른쪽에서 걸어 들어와 말풍선을 열고 인사 | 화면 녹화, 데스크톱 배경은 단색 |
| 낮 → 밤 종이 | 시스템 어두운 모드를 켜면 열린 창이 모두 밤 종이로 | 화면 녹화 3초 |
| 한 목록, 두 기기 | Mac에서 체크 → 공유 폴더 → Windows 목록에 반영 | 두 화면을 나란히 녹화 |
| 집중 카드 | '보고서 25분 집중' 입력 → 카드 → 다 했어요 | 화면 녹화 (시간은 빨리 감기) |
| 세 언어 | 같은 화면을 한국어, 영어, 네덜란드어로 차례로 | 스냅숏 세 장을 이어 붙인 GIF |

녹화할 때는 `--demo`로 띄우면 예시 목록을 임시 저장소에 써서 실제 데이터가 나오지 않는다(Mac은 `./scripts/build.sh` 뒤 `dist/종이냥.app/Contents/MacOS/PaperTodo --demo`, Windows는 `npm start -- --demo`).
