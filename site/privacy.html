Windows의 화면 상태

Windows 앱의 바탕인 Electron이 %APPDATA%\종이냥\에 마지막으로 연 탭 같은 화면 상태와 캐시를 둬요.

기기 밖으로 나가는 길

기록이 이 컴퓨터 밖으로 나가는 길은 셋뿐이에요. 셋 다 처음에는 닫혀 있고, 내가 열어야 열려요.

  • 두 앱에는 인터넷에 연결하는 코드가 없어요. 사용 통계, 오류 보고, 광고, 업데이트 확인도 없어요.
  • 링크를 눌렀을 때만 기본 브라우저가 열려요. 메모 속 링크나 Claude 데스크톱을 내려받는 곳이 그래요.
  • 알림과 알람은 이 컴퓨터 안에서만 울려요.
  • 공유 폴더를 써도 종이냥은 그 서비스에 로그인하거나 직접 연결하지 않아요. 폴더 안의 파일만 읽고 써요.

타닥냥

타닥냥은 글자를 치면 화면 구석에서 앞발로 두드리는 고양이예요. 종이냥 펫과 따로 켜고 꺼요.

종이냥이 아는 것

  • 키를 눌렀다는 사실과 그 시각
  • 키를 꾹 누르고 있는지
  • 단축키(⌘ · ⌃, Windows는 Ctrl)인지

모르는 것

  • 어떤 키를 눌렀는지
  • 무엇을 쳤는지, 조합 중인 글
  • 클립보드

앱에서책상 › 종이냥 › 타닥냥 › 두드리기

  • 아는 것도 저장하거나 기록에 남기거나 보내지 않아요. 단축키를 칠 때와 꾹 누를 때는 두드리지 않으려고 보는 거예요.
  • 처음에는 종이냥의 창에서 칠 때만 반응해요. 이때는 권한이 필요 없어요.
  • Mac에서 ‘모든 앱에서’⁠를 고르면 다른 앱에서 칠 때도 반응해요. 이때 macOS의 입력 모니터링 권한이 필요해서, 고르는 순간 macOS가 한 번 물어요. 듣기만 하는 방식이라 다른 앱의 입력을 바꾸거나 막지 않아요.
  • Mac에서 권한을 끄거나, 설정을 끄거나, 화면을 잠그거나, 앱을 끝내면 다른 앱의 키는 더 받지 않아요. 권한은 시스템 설정 › 개인정보 보호 및 보안 › 입력 모니터링에서 언제든 끌 수 있어요.
  • Windows에서 ‘모든 앱에서’⁠를 고르면 Windows의 키보드 후크로 다른 앱의 키를 들어요. 키 코드는 꾹 누른 키를 가리는 동안만 잠깐 보고 남기지 않아요. 키는 그대로 다음 앱으로 넘겨서 바꾸거나 막지 않아요.
  • Windows에서도 설정을 끄거나, 화면을 잠그거나, 앱을 끝내면 바로 다른 앱의 키를 더 받지 않아요. 키로거와 같은 방법이라 백신이 물어볼 수 있어서, 처음에는 꺼져 있어요.

AI 연결을 켜면

종이냥 for Claude는 Claude 데스크톱이나 Claude Code와 이야기하면서 할 일을 보고 넣는 기능이에요. 처음에는 꺼져 있어요.

Claude가 하는 것

  • 할 일 · 반복 · 일정 · 알람 · 메모 · 집중 기록 · 완료 기록 읽기
  • 할 일 · 일정 · 메모 넣기
  • 바뀌기 전과 후를 보여 주고, ‘응’⁠이라고 하면 고치기

하지 않는 것

  • 지우기
  • 스스로 인터넷에 연결하기
  • 스위치가 꺼져 있을 때 읽거나 쓰기

앱에서책상 › AI 연결

  • 켜 두면 Claude가 대화에 필요할 때 이 컴퓨터에서 종이냥 for Claude를 실행해요. 할 일과 반복하지 않는 일정은 바뀌기 전과 후를 보여 주고 확인을 받은 뒤에 고쳐요.
  • Claude가 읽은 내용은 대화의 일부로 Claude에게 가요. 그 대화는 내 Claude 계정의 설정과 Anthropic의 개인정보 처리방침에 따라 다뤄져요.
  • 종이냥 for Claude는 종이냥의 저장 폴더와 앱 폴더의 파일만 읽고 써요.
  • Claude가 넣거나 고친 것은 바뀌기 전과 후를 ai-log.jsonl에 한 줄씩 남겨요. 되돌리기와 ‘최근 AI 작업’⁠이 이 기록을 써요. 이 기기에만 있고, 1MB를 넘으면 최근 30일만 남겨요.
  • 스위치는 Claude가 부를 때마다 다시 읽어요. 그래서 끄는 순간부터 Claude는 종이냥의 파일을 아무것도 읽거나 쓰지 못해요.

알아 둘 것

좋은 점만 적으면 안내가 아니라서, 종이냥이 지켜 주지 않는 것도 적어 둘게요.

파일은 암호화하지 않아요
저장 폴더의 파일은 사람이 읽을 수 있는 JSON이에요. 이 컴퓨터의 내 계정에 들어올 수 있는 사람과 프로그램은 읽을 수 있어요. 컴퓨터를 잃어버릴 때를 생각하면 디스크 암호화(Mac의 FileVault, Windows의 BitLocker나 장치 암호화)⁠를 켜 두는 게 좋아요.
백업 파일에는 모든 것이 들어 있어요
내보낸 백업 파일(.jongi)도 암호화하지 않아요. 할 일 · 메모 · 일정 · 기록이 모두 들어 있어서, 건네면 그 사람이 모두 볼 수 있어요.
숨긴 스페이스는 잠금이 아니에요
이 기기에서 숨긴 스페이스의 할 일은 Claude의 오늘과 목록에서도 빠져요. 하지만 스페이스 이름을 말하면 ‘숨김’ 표시와 함께 보여 줘요. 보여 주지 않을 뿐, 읽지 못하게 막지는 않아요.
공유 폴더 안의 보호는 그 서비스가 맡아요
공유 폴더로 옮기는 동안과 서비스의 서버에 있는 동안의 보호는 종이냥이 아니라 그 서비스가 맡아요.
코드 서명이 없어요
두 앱 모두 코드 서명을 하지 않은 빌드예요. 받은 파일이 올린 그대로인지는 파일 확인값으로 확인해 주세요.

직접 확인해 보세요

이 쪽의 말을 믿지 않아도 돼요. 아래 세 가지는 누구나 할 수 있어요.

  1. 코드를 읽어요

    소스 코드가 모두 공개돼 있어요. 앱 밖으로 나가는 길은 몇 파일에 모여 있어요.

    • Windows: 링크를 브라우저로 넘기는 곳
    • Windows: 열어도 되는 링크와 막는 창
    • Mac: 타닥냥이 키를 듣는 곳
    • Windows: 타닥냥의 키보드 후크
    • Claude 확장: 스위치를 읽는 곳

  2. 받은 파일을 맞춰 봐요

    릴리스마다 파일의 SHA-256 값을 적어 둬요. 받은 파일의 값이 같으면 올린 그대로예요.

    받은 파일 확인하는 법 →

  3. 연결을 지켜봐요

    종이냥을 켜 둔 채 네트워크를 봐요. 보낸 양과 받은 양이 0이어야 해요.

    • Mac: 활성 상태 보기 › 네트워크에서 ‘종이냥’⁠의 보낸 바이트와 받은 바이트를 봐요. 터미널에서는 lsof -nP -i -a -c PaperTodo가 아무것도 보여 주지 않아야 해요.
    • Windows: 리소스 모니터 › 네트워크에서 ‘종이냥’⁠을 찾아요.

우리가 해 본 것 2026년 11월 10일 · Mac 1.49.1 · Windows 1.34.1

  • 두 앱과 Claude 확장의 코드에서 인터넷에 연결하는 부분을 찾아봤어요. 누른 링크를 기본 브라우저에 넘기는 곳뿐이고, 직접 연결하는 코드는 없었어요.
  • Windows 앱의 화면 파일 22개는 모두 앱 안의 파일만 불러오게 막혀 있어요(콘텐츠 보안 정책).
  • Mac 앱의 시험용 사본을 화면 밖에서 1분 45초 동안 켜 두고, 1초마다 100번 연결을 살펴봤어요. 노트를 쓰고 완료 기록을 여는 동안에도 열린 인터넷 연결은 0개였어요.
  • Windows 앱은 아직 실제 Windows PC에서 연결을 지켜보지 못했어요. 확인하면 여기에 적을게요.

이 사이트

  • 쿠키와 분석 도구를 쓰지 않아요.
  • 글꼴, 그림, 영상은 모두 이 사이트에서 받아요. 페이지를 여는 동안 다른 곳으로 가는 요청이 없어요.
  • 낮 종이나 밤 종이를 고르면 그 선택만 이 브라우저에 남아요(localStorage). ‘시스템 따라가기’⁠를 누르면 지워져요.
  • 사이트는 GitHub Pages에서 열리고, 내려받기와 문서 링크는 GitHub으로 이어져요. 그때의 접속 기록은 GitHub이 자기 정책에 따라 다뤄요.

모두 지우고 싶을 때

종이냥이 남기는 것은 위의 폴더와 설정이 전부예요. 아래 순서로 지우면 아무것도 남지 않아요. 앱만 지우면 목록은 그대로 남아요.

Mac

  1. AI 연결을 썼다면 Claude에서 먼저 떼요. Claude 데스크톱의 설정 › 확장 프로그램에서 ‘종이냥 for Claude’⁠를 지우고, Claude Code에 연결했다면 claude mcp remove -s user jongi-nyang을 실행해요.
  2. 책상 › 꾸미기 › 시작에서 ‘로그인할 때 같이 열기’⁠를 꺼요. 앱을 먼저 지웠다면 시스템 설정 › 일반 › 로그인 항목에서 지워요.
  3. 종이냥을 종료하고 응용 프로그램 폴더의 종이냥을 휴지통으로 옮겨요.
  4. ~/Library/Application Support/com.noa.PaperTodo/ 폴더를 지워요. 목록, AI 연결 기록, 자동 백업이 모두 여기 있어요.
  5. 설정을 지워요. 터미널에서 defaults delete com.noa.PaperTodo를 실행하면 ~/Library/Preferences/com.noa.PaperTodo.plist가 지워져요.

Windows

  1. AI 연결을 썼다면 Claude에서 먼저 떼요. Claude 데스크톱의 설정 › 확장 프로그램에서 ‘종이냥 for Claude’⁠를 지우고, Claude Code에 연결 명령을 붙여 넣었다면 그 폴더에서 claude mcp remove jongi-nyang을 실행해요.
  2. 책상 › 꾸미기 › 시작에서 ‘컴퓨터를 켤 때 같이 열기’⁠를 꺼요. 앱을 먼저 지웠다면 작업 관리자 › 시작 앱에서 꺼요.
  3. 알림 영역에서 종이냥을 종료하고, 설정 › 앱 › 설치된 앱에서 종이냥을 제거해요. ZIP으로 받았다면 푼 폴더를 지워요. 제거해도 목록은 남아요.
  4. %APPDATA%\PaperTodo\ 폴더를 지워요. 목록, 설정, AI 연결 기록, 자동 백업이 모두 여기 있어요.
  5. %APPDATA%\종이냥\ 폴더(화면 상태와 캐시)⁠를 지워요.

두 앱 모두

  • 공유 폴더를 썼다면 그 폴더의 todos.json, memos.json, repeats.json, memo-folders.json, todo-spaces.json, events.json, alarms.json, focus.jsonl, archive 폴더를 지워요. 같은 폴더를 쓰는 다른 기기에서도 목록이 사라져요.
  • 내보낸 백업 파일(.jongi)은 저장한 곳에서 따로 지워요.

자주 묻는 것

종이냥을 만든 사람이 내 할 일을 볼 수 있어요?

아니요. 종이냥에는 기록을 받는 서버가 없고, 앱이 스스로 인터넷에 연결하지 않아요. 만든 사람이 보는 건 내가 GitHub 이슈에 직접 적은 것뿐이에요.

인터넷이 없어도 다 돼요?

네. 할 일, 메모, 일정, 알람, 백업이 모두 인터넷 없이 돼요. 인터넷이 필요한 건 공유 폴더 서비스와 Claude처럼 내가 연결한 다른 서비스예요.

새 버전이 나온 건 어떻게 알아요?

앱이 확인하지 않아요. 인터넷에 연결하지 않기 때문이에요. 이 사이트나 GitHub 릴리스에서 확인해 주세요. 새 버전을 처음 열면 목록을 먼저 백업해 둬요.

Claude가 내 메모를 지우거나 몰래 고칠 수 있어요?

지우는 기능이 없어요. 할 일과 반복하지 않는 일정은 바뀌기 전과 후를 보여 주고, ‘응’⁠이라고 해야 고쳐요. Claude가 넣거나 고치면 알림이 뜨고 바로 되돌릴 수 있어요.

타닥냥이 비밀번호를 알 수 있어요?

아니요. 종이냥은 어떤 키를 눌렀는지 읽지 않아요. 키를 눌렀다는 사실과 그 시각만 알아요. 비밀번호 칸에서 칠 때도 같아요.

공유 폴더를 쓰면 기록이 암호화돼요?

종이냥은 따로 암호화하지 않아요. 옮기는 동안과 서버에 있는 동안의 보호는 그 서비스가 맡아요. 서비스의 설정과 정책을 확인해 주세요.
