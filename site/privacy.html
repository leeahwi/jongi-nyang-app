종이냥에는 계정도 서버도 없어서 모으는 정보가 없어요. 무엇이 어디에 저장되고, 언제 기기 밖으로 나갈 수 있는지 여기에 모두 적어 둘게요.

Mac 1.48 · Windows 1.33 기준 · 2026년 11월 7일

  • 모으지 않아요회원 가입, 사용 통계, 오류 보고, 광고가 없어요. 앱은 스스로 인터넷에 연결하지 않아요.
  • 파일로 저장해요할 일, 메모, 일정은 내 컴퓨터의 폴더에 파일로 있어요. 폴더는 내가 바꿀 수 있어요.
  • AI 연결은 켤 때만처음에는 꺼져 있어요. 켜면 Claude가 읽은 내용이 대화와 함께 Claude로 가요.
  • 사이트도 조용히쿠키와 분석 도구가 없고, 글꼴과 그림도 이 사이트에서 받아요.

저장되는 곳

모두 내 컴퓨터 안에 있어요. 종이냥을 만든 사람에게도 보이지 않아요.

할 일 · 메모 · 일정 · 알람 · 반복 · 스페이스 · 완료 기록 · 집중 기록

저장 폴더에 JSON 파일로 있어요. 처음에는 앱 폴더이고, 책상 → 저장과 백업에서 다른 폴더로 바꿀 수 있어요.

Mac ~/Library/Application Support/com.noa.PaperTodo/

Windows %APPDATA%\PaperTodo\

설정

글꼴, 알림, 고른 저장 폴더, 바탕화면 위젯, 음력 · 공휴일 같은 설정은 기기마다 따로 있고 공유 폴더로 가지 않아요.

Mac ~/Library/Preferences/com.noa.PaperTodo.plist

Windows %APPDATA%\PaperTodo\settings.json, storage.json

AI 연결 설정과 기록

ai-link.json과 ai-log.jsonl이에요. 공유 폴더를 써도 이 기기의 앱 폴더(위의 기본 폴더)에 남아요.

자동 백업

하루 한 번, 그리고 가져오기나 되돌리기처럼 덮어쓰기 전마다 저장 폴더를 앱 폴더의 backups에 백업 파일(.jongi)로 남겨요. 매일 백업은 14개, 덮어쓰기 전 백업은 종류마다 10개만 남겨요. 공유 폴더를 써도 이 기기에만 있어요.

Windows의 화면 상태

Windows 앱의 바탕인 Electron이 %APPDATA%\종이냥\에 마지막으로 연 탭 같은 화면 상태와 캐시를 둬요.

밖으로 보내지 않아요

  • 두 앱에는 인터넷에 연결하는 코드가 없어요. 사용 통계, 오류 보고, 광고, 업데이트 확인도 없어요.
  • 링크를 눌렀을 때만 기본 브라우저가 열려요. 메모 속 링크나 Claude 데스크톱을 내려받는 곳이 그래요.
  • 알림과 알람은 이 컴퓨터 안에서만 울려요.

글자 칠 때 두드리는 고양이

글자를 치면 종이냥이 앞발로 두드려요. 이때 종이냥이 아는 건 키를 눌렀다는 사실과 그 시각뿐이에요.

  • 어떤 키인지, 무엇을 쳤는지, 조합 중인 글, 클립보드는 읽지 않아요. 저장하거나 기록에 남기거나 보내지도 않아요.
  • 키를 꾹 누르고 있는지, 단축키(⌘ · ⌃, Windows는 Ctrl)인지만 봐요. 그럴 때는 두드리지 않아요.
  • 처음에는 종이냥의 창에서 칠 때만 반응해요. 이때는 권한이 필요 없어요.
  • Mac에서 ‘모든 앱에서’를 고르면 다른 앱에서 칠 때도 반응해요. 이때 macOS의 입력 모니터링 권한이 필요해서, 고르는 순간 macOS가 한 번 물어요. 허락해도 종이냥이 아는 건 위와 같이 키를 눌렀다는 사실뿐이에요. 다른 앱의 입력을 바꾸거나 막지 않아요.
  • 권한을 끄거나, 설정을 끄거나, 펫을 숨기거나, 앱을 끝내면 다른 앱의 키는 더 받지 않아요. 권한은 시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링에서 언제든 끌 수 있어요.
  • Windows 앱은 다른 앱의 키를 받지 않아요.

AI 연결을 켜면

종이냥 for Claude는 Claude 데스크톱이나 Claude Code와 이야기하면서 할 일을 보고 넣는 기능이에요. 처음에는 꺼져 있고, 책상 → AI 연결에서 켜요.

  • 켜 두면 Claude가 대화에 필요할 때 이 컴퓨터에서 종이냥 for Claude를 실행해요. 저장 폴더의 할 일 · 일정 · 알람 · 메모 · 집중 기록 · 완료 기록을 읽고, 할 일 · 일정 · 메모를 넣어요. 할 일과 반복하지 않는 일정은 바뀌기 전과 후를 보여 주고 확인을 받은 뒤에 고쳐요. 지우지는 않아요.
  • Claude가 읽은 내용은 대화의 일부로 Claude에게 가요. 그 대화는 내 Claude 계정의 설정과 Anthropic의 개인정보 처리방침에 따라 다뤄져요.
  • 종이냥 for Claude는 스스로 인터넷에 연결하지 않아요. 종이냥의 저장 폴더와 앱 폴더의 파일만 읽고 써요.
  • Claude가 넣거나 고친 것은 바뀌기 전과 후를 ai-log.jsonl에 한 줄씩 남겨요. 되돌리기와 ‘최근 AI 작업’이 이 기록을 써요. 이 기기에만 있고, 1MB를 넘으면 최근 30일만 남겨요.
  • 이 기기에서 숨긴 스페이스의 할 일은 Claude의 오늘과 목록에서 빠져요. 스페이스 이름을 말하면 ‘숨김’ 표시와 함께 보여 줘요. 보여 주지 않을 뿐, Claude가 읽지 못하게 막지는 않아요.
  • 스위치를 끄면 Claude는 종이냥의 파일을 아무것도 읽거나 쓰지 못해요.

공유 폴더와 백업 파일

  • iCloud Drive, OneDrive, Dropbox 같은 공유 폴더를 저장 폴더로 고르면, 파일을 다른 기기로 옮기는 건 그 서비스예요. 그 서비스의 약관과 개인정보 정책을 따라요.
  • 종이냥은 그 서비스에 로그인하거나 직접 연결하지 않아요. 폴더 안의 파일만 읽고 써요.
  • 백업 파일(.jongi)은 내가 고른 곳에 저장돼요. 할 일 · 메모 · 일정 · 기록이 모두 들어 있어서, 다른 사람에게 보내면 그 내용을 모두 볼 수 있어요.

이 사이트

  • 쿠키와 분석 도구를 쓰지 않아요.
  • 글꼴, 그림, 영상은 모두 이 사이트에서 받아요. 페이지를 여는 동안 다른 곳으로 가는 요청이 없어요.
  • 낮 종이나 밤 종이를 고르면 그 선택만 이 브라우저에 남아요(localStorage). ‘시스템 따라가기’를 누르면 지워져요.
  • 사이트는 GitHub Pages에서 열리고, 내려받기와 문서 링크는 GitHub으로 이어져요. 그때의 접속 기록은 GitHub이 자기 정책에 따라 다뤄요.

모두 지우고 싶을 때

종이냥이 남기는 것은 위의 폴더와 설정이 전부예요. 아래 순서로 지우면 아무것도 남지 않아요. 앱만 지우면 목록은 그대로 남아요.

Mac

  1. AI 연결을 썼다면 Claude에서 먼저 떼요. Claude 데스크톱의 설정 → 확장 프로그램에서 ‘종이냥 for Claude’를 지우고, Claude Code에 연결했다면 claude mcp remove -s user jongi-nyang을 실행해요.
  2. 책상 → 꾸미기 → 시작에서 ‘로그인할 때 같이 열기’를 꺼요. 앱을 먼저 지웠다면 시스템 설정 → 일반 → 로그인 항목에서 지워요.
  3. 종이냥을 종료하고 응용 프로그램 폴더의 종이냥을 휴지통으로 옮겨요.
  4. ~/Library/Application Support/com.noa.PaperTodo/ 폴더를 지워요. 목록, AI 연결 기록, 자동 백업이 모두 여기 있어요.
  5. 설정을 지워요. 터미널에서 defaults delete com.noa.PaperTodo를 실행하면 ~/Library/Preferences/com.noa.PaperTodo.plist가 지워져요.

Windows

  1. AI 연결을 썼다면 Claude에서 먼저 떼요. Claude 데스크톱의 설정 → 확장 프로그램에서 ‘종이냥 for Claude’를 지우고, Claude Code에 연결 명령을 붙여 넣었다면 그 폴더에서 claude mcp remove jongi-nyang을 실행해요.
  2. 책상 → 꾸미기 → 시작에서 ‘컴퓨터를 켤 때 같이 열기’를 꺼요. 앱을 먼저 지웠다면 작업 관리자 → 시작 앱에서 꺼요.
  3. 알림 영역에서 종이냥을 종료하고, 설정 → 앱 → 설치된 앱에서 종이냥을 제거해요. ZIP으로 받았다면 푼 폴더를 지워요. 제거해도 목록은 남아요.
  4. %APPDATA%\PaperTodo\ 폴더를 지워요. 목록, 설정, AI 연결 기록, 자동 백업이 모두 여기 있어요.
  5. %APPDATA%\종이냥\ 폴더(화면 상태와 캐시)⁠를 지워요.

두 앱 모두

  • 공유 폴더를 썼다면 그 폴더의 todos.json, memos.json, repeats.json, memo-folders.json, todo-spaces.json, events.json, alarms.json, focus.jsonl, archive 폴더를 지워요. 같은 폴더를 쓰는 다른 기기에서도 목록이 사라져요.
  • 내보낸 백업 파일(.jongi)은 저장한 곳에서 따로 지워요.
