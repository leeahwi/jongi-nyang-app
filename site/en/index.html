Tour

One screen at a time

01 · The note

A note that puts now first

One sheet of paper with Today, Ahead and Memo tabs. The day strip at the top shows what's on now in large handwriting and the time left in a ring; what's next and today's list follow below.

02 · Timetable

Your day, unfolded

Click the day strip and the day unfolds as a timetable right there. A dragged block follows the mouse and settles on a quarter hour; drag its top or bottom edge to stretch it.

03 · Focus

Focus on one thing

Type “report 25 min focus” and the note turns into a single card with Done, 5 more min and Not now. Pomodoro rounds work too.

04 · Alarms

Alarms on a paper slip

Set days, sound and snooze. When it rings, a slip appears with the cat shaking a bell. It ignores keys for 1.5 seconds, so typing in another app can't dismiss it.

05 · Ahead

Drag to reschedule

Each day of this week and next with its events and due to-dos. Drag a to-do onto another day and its due date follows.

06 · Desk

Calendar and settings on the Desk

Calendar, history, settings and help live in one Desk window, so the note itself stays light.

Mac and Windows, one list

Pick the same cloud folder as the storage location and both computers share one list. Edits made at nearly the same time both survive, and a memo edited on two devices is merged line by line and character by character. No account, no server.

Night paper

When the system is in dark mode, every window switches to night paper, the color of paper in a room with the lights off. Every text pair, day and night, passes WCAG AA contrast.

How it's built

Built twice, kept identical

Swift (SwiftUI + AppKit) on the Mac, Electron + TypeScript on Windows, built separately. They share no code. Both have to pass the same tables of test cases, which keeps their behavior the same.

136 rowsof input-line cases both apps pass character for character
471 + 300Windows tests; Mac test scripts with ~300 checks
61% → 0.7%Mac idle CPU with the note open
WCAG AAevery text pair, day and night, or the check fails
  • Case tables come firstHow “meeting tomorrow 3pm” is read, down to the words on the chip, is one row. The Swift and TypeScript tests must both produce that exact string.
  • Screens are checked by rendering themAbout 1,500 real Mac screens in 3 languages, day and night. Every Windows window is resized and redrawn at different scale factors and fonts to catch clipped text.
  • Where the 61% CPU came fromA blinking “now” line was redrawing the whole note every frame. The same release cut input latency from 0.46 s to 0.01 s and launch from 2.7 s to 1.0 s on the Mac; on Windows, memory after 10 minutes went from 692 MB to 457 MB.
  • Not done yetThe Windows version has only run in Electron on macOS, never on a real Windows PC. Neither app is code-signed.

FAQ

Questions, answered

Is it really free?

Yes. No payments and no locked features. The source code is on GitHub under the Apache License 2.0.

Do I need an account? Where are my notes kept?

No account and no server. Everything is saved as files in a folder you choose. Change it under Desk → Storage & backup.

Can I use it on a Mac and a Windows PC together?

Choose a folder both computers can see, such as iCloud Drive, OneDrive or Dropbox, as the storage location and they share one list. Edits made at nearly the same time both survive.

Does it connect to Google Calendar?

No. It once did, and it worked, but I wanted to keep personal plans and work apart, and the people testing it said the same. The reasoning is in the decision log (Korean).

Why is it blocked the first time I open it?

The builds aren't code-signed. On the Mac, right-click the app in Applications and choose Open. On Windows, choose More info → Run anyway in SmartScreen.

Which languages and systems?

Korean, English and Dutch. macOS 14 or later on Apple Silicon; Windows 10/11 x64. The Windows version was checked in Electron on macOS and hasn't been tested on a real Windows PC yet.
