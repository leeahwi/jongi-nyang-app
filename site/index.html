01 · 노트

지금 하는 일이 먼저 보이는 노트

오늘, 앞으로, 메모 탭이 있는 종이 한 장이에요. 맨 위 하루 띠에는 지금 하는 일이 손글씨로 크게, 남은 시간이 동그라미로 보이고, 아래에 다음 일과 오늘 할 일이 이어져요.

02 · 하루 일정표

누르면 펼쳐지는 하루

하루 띠를 누르면 그 자리에서 하루 일정표가 펼쳐져요. 블록을 끌면 마우스를 따라오다 15분 칸에 놓이고, 위아래 끝을 끌면 시간이 늘거나 줄어요.

03 · 집중

할 일 하나에 집중

‘보고서 25분 집중’이라고 적으면 노트가 카드 한 장으로 바뀌어요. ‘다 했어요’, ‘5분 더’, ‘다음에’ 단추가 있고 뽀모도로 라운드도 돼요.

04 · 알람

종이 쪽지로 울리는 알람

요일, 소리, 다시 울림을 정해요. 울리면 종이냥이 종을 흔드는 쪽지가 뜨고, 뜬 뒤 1.5초는 키를 받지 않아서 다른 앱에서 치던 글자로 꺼지지 않아요.

05 · 앞으로

끌어서 날짜 바꾸기

이번 주와 다음 주의 날마다 일정과 마감이 함께 보여요. 할 일을 다른 날로 끌어 놓으면 마감이 그날로 바뀌어요.

06 · 책상

달력과 설정은 책상 창에

달력, 완료 기록, 설정, 도움말을 책상 창 하나에 모았어요. 노트는 가볍게 두고, 길게 볼 일은 여기서 봐요.

만든 방식

두 번 만들고, 같게 지켰어요

Mac은 Swift(SwiftUI + AppKit), Windows는 Electron + TypeScript로 따로 만들었어요. 코드는 나누지 않고, 두 앱이 같은 시험 사례 표를 통과하게 해서 동작을 맞춰요.

  • 사례 표를 먼저 써요‘내일 3시 회의’를 무엇으로 읽고 칩에 무엇이 보이는지까지 한 줄로 적어요. Swift 시험과 TypeScript 시험이 같은 문자열을 내야 통과해요.
  • 화면은 그려서 확인해요Mac은 실제 화면을 3개 언어와 낮/밤으로 약 1,500장 그리고, Windows는 창마다 크기와 배율, 글꼴을 바꿔 가며 잘린 글을 찾아요.

  • 아직 못 한 것Windows 판은 macOS 위 Electron에서만 확인했고, 실제 Windows PC에서는 돌려 보지 않았어요. 두 앱 모두 코드 서명이 없어요.

질문

자주 묻는 것

정말 무료예요?

네, 무료예요. 결제나 잠긴 기능이 없어요. 소스 코드는 Apache License 2.0으로 GitHub에 있어요.

계정이 필요해요? 내 기록은 어디에 있어요?

계정도 서버도 없어요. 내가 고른 폴더에 파일로 저장해요. 저장 위치는 책상 → 저장과 백업에서 바꿔요.

Mac과 Windows에서 같이 쓸 수 있어요?

iCloud Drive, OneDrive, Dropbox처럼 두 컴퓨터가 같이 보는 폴더를 저장 위치로 고르면 같은 목록을 써요. 거의 동시에 고쳐도 양쪽 변경이 남아요.

Google 캘린더와 연결돼요?

아니요. 한때 만들어 잘 동작했지만, 개인 일정과 업무를 나누고 싶어서 뺐어요. 같이 써 본 사람들도 같은 말을 했어요. 이유는 결정 기록에 적었어요.

처음 열 때 왜 막혀요?

코드 서명이 없는 빌드라서 그래요. Mac은 응용 프로그램 폴더에서 우클릭 → 열기, Windows는 SmartScreen에서 추가 정보 → 실행을 눌러요.

어떤 언어와 환경에서 돼요?

한국어, English, Nederlands. Mac은 macOS 14 이상의 Apple Silicon, Windows는 10/11 x64예요. Windows 판은 macOS 위 Electron에서 확인했고 실제 Windows PC에서는 아직 시험하지 못했어요.
