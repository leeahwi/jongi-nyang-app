01 · 노트

지금 하는 일이 먼저 보이는 노트

오늘, 앞으로 탭이 달린 종이 한 장이에요. 맨 위 하루 띠에 지금 하는 일이 손글씨로 크게 적히고, 남은 시간은 옆 동그라미에 보여요. 그 아래로 다음 일정과 오늘 할 일이 이어져요.

02 · 하루 일정표

누르면 펼쳐지는 하루

하루 띠를 누르면 그 자리에서 하루 일정표가 펼쳐져요. 블록을 끌면 마우스를 따라오다가 15분 칸에 놓여요. 위아래 끝을 끌면 길이가 바뀌어요.

03 · 집중

할 일 하나에 집중

‘보고서 25분 집중’⁠이라고 적으면 노트가 카드 한 장으로 바뀌어요. 끝나면 ‘다 했어요’, ‘5분 더’, ‘다음에’ 중에 골라요. 뽀모도로처럼 여러 번 돌릴 수도 있어요.

04 · 알람

종이 쪽지로 울리는 알람

요일과 소리, 다시 울림을 정해 둬요. 시간이 되면 종이냥이 종을 흔드는 쪽지가 떠요. 다른 앱에서 타자를 치다가 실수로 끄지 않도록, 뜬 뒤 1.5초 동안은 키를 받지 않아요.

05 · 앞으로

끌어서 날짜 바꾸기

이번 주와 다음 주를 날짜별로 펼쳐 보여 줘요. 일정과 마감이 한곳에 모여 있어요. 할 일을 다른 날로 끌어 놓으면 마감도 그날로 옮겨져요.

06 · 책상

달력과 설정은 책상 창에

달력, 완료 기록, 설정, 도움말은 책상 창에 모았어요. 노트는 작게 띄워 두고, 한 달을 넘겨 볼 때만 책상 창을 열면 돼요. 달력에는 음력 날짜와 공휴일 이름도 보여요.

Mac과 Windows, 한 목록

두 컴퓨터에서 같은 공유 폴더를 저장 위치로 고르면 목록 하나를 같이 써요. 거의 같은 때 양쪽에서 고쳐도 변경이 다 남고, 같은 메모는 두 글을 합쳐요. 파일은 그 클라우드 서비스가 옮겨요.

밤 종이

시스템이 어두운 모드면 창이 모두 불 끈 방의 종이 색으로 바뀌어요. 책상 → 꾸미기의 ‘낮 · 밤’⁠에서 하나로 정해 둘 수도 있어요. 글자 대비는 낮과 밤 모두 웹 접근성 기준(WCAG AA)⁠에 맞췄어요.

타닥냥

글자를 치면 구석에서 같이 두드려요

타닥냥은 화면 구석에서 방석에 기대 앞발로 두드리는 고양이예요. 종이냥 펫과 따로 켜고 끄고, 책상 → 종이냥의 ‘타닥냥’ 칸에서 정해요.

  • 어디서 칠 때 두드릴지‘두드리기’에서 끄기 · 종이냥에서만 · 모든 앱에서 가운데 골라요. 종이냥에서만이면 칠 때 나왔다가, 멈추고 3초 뒤 조용히 들어가요.
  • 네 구석 가운데 한 곳‘자리’에서 화면의 네 구석 가운데 골라요. 클릭은 뒤의 창으로 가서 하던 일을 막지 않고, 전체 화면 앱 위에도 보여요.
  • 고양이 크기도 네 가지타닥냥과 펫 모두 작게 · 보통 · 크게 · 아주 크게 가운데 골라요. 두 고양이의 크기는 따로예요. 펫이 커지면 말풍선과 질문 버튼 자리도 따라가요.
  • 어떤 키인지는 몰라요키를 눌렀다는 것만 알고, 무엇을 쳤는지는 읽지도 남기지도 않아요. ‘모든 앱에서’는 Mac에서 입력 모니터링 권한이 필요하고, Windows에서는 아직 실제 PC에서 보지 못했어요. 자세한 건 개인정보 안내에 있어요.

달력 위젯

바탕화면에 종이 달력을 둬요

오늘부터 이번 달 벽 달력까지 일곱 가지 위젯 가운데 골라 4개까지 둬요. 음력 날짜와 한국 공휴일 이름도 처음부터 보여요. 책상 → 일정 → 바탕화면 위젯에서 더해요.

  • 날짜를 누르면 쪽지위젯에서 날짜를 누르면 그날의 일이 모두 보여요. 노트의 입력 줄처럼 적어서 바로 넣어요.
  • 크기는 네 가지위젯마다 작게 · 보통 · 크게 · 아주 크게 가운데 골라요. 글자, 칸, 여백이 같은 비율로 바뀌어서 크게 해도 칸이 비거나 이름이 잘리지 않아요. 화면에 들어가지 않는 크기는 흐리게 보여요.
  • 옅게 둬도 읽혀요불투명도를 20–100%에서 골라요. 날마다 종이 타일이 깔려서 옅게 해도 글자가 읽혀요. 내 바탕화면에서 어떻게 보이는지는 아직 실제 화면에서 보지 못했어요.
  • 귀를 끌어 옮겨요오른쪽 위 고양이 귀를 끌면 위젯이 옮겨지고, 누르면 크기와 ‘항상 위에 두기’⁠가 있는 메뉴가 열려요. 처음에는 다른 창 아래, 바탕화면에 있어요.

반복과 달력

반복 할 일도 달력에 미리 보여요

‘매주 월 분리수거’처럼 반복하는 할 일이 앞으로 돌아올 날마다 보여요. 책상 달력, 위젯, 날짜 쪽지, 벽 달력이 모두 같아요.

  • 다음 한 번만 진하게다음에 할 한 번은 진하고, 그 뒤는 흐려요. 흐린 줄을 누르면 그 할 일을 노트에서 보여 줘요.
  • 매일 반복은 ⟲와 개수로매일 · 평일 반복은 이름 대신 날짜 옆에 ⟲와 개수로 보여요. 그래서 일정과 마감이 칸을 먼저 써요. ⟲에 마우스를 올리면 이름이 보여요.
  • 키보드로 일정 열기책상 달력에서 날을 고르고 Tab을 누르면 그날의 첫 일정으로 가요. ↑ ↓로 옮기고 Return(Windows는 Enter)⁠으로 고치기 쪽지를 열어요. Esc를 누르면 날로 돌아가요.
  • 음력이 잘리지 않아요날짜 줄에 자리가 모자라면 음력을 ‘10.1’처럼 줄이고, 그래도 모자라면 반복 개수부터 빼요. 글자가 칸 밖으로 나가지 않아요.

열다섯 종이

종이를 고르면 창이 모두 바뀌어요

책상 → 꾸미기 → 종이에서 고르면 노트, 달력, 위젯, 쪽지, 책상, 메모 서랍이 같은 종이로 바뀌어요. 밝은 종이 열하나, 어두운 종이 넷이에요.

  • 새 종이 일곱노란 메모지, 원고지, 하늘색 줄노트, 라벤더 종이, 재생지, 밤하늘 종이, 칠판이 생겼어요. 노란 메모지와 칠판이 오래 봐도 눈이 편한지는 아직 확인하지 못했어요.
  • 밤에는밝은 종이는 밤이 되면 ‘밤에는’⁠에서 고른 종이로 바뀌어요. 밤 종이, 먹색 종이, 밤하늘 종이, 칠판, 그대로 가운데 골라요.
  • 서랍만 따로메모 서랍은 처음에 노트와 같은 종이예요. 책상 → 메모 서랍에서 ‘노트와 같은 종이’⁠를 끄면 서랍 종이만 따로 골라요.
  • 업데이트해도 그대로처음에는 낮 종이, 밤에는 밤 종이예요. 메모 서랍에 따로 고른 종이도 그대로 남아요.

할 일 스페이스

나눠도 오늘은 한 장

할 일을 회사, 집, 공부처럼 스페이스로 나눠요. 오늘 한 장에는 그대로 모두 보이고, 줄 왼쪽 끝에 그 스페이스의 색 띠만 붙어요.

  • 한 스페이스만 보기머리말의 ‘모든 스페이스 ▾’⁠에서 고르거나 ⌥⌘1–9(Windows는 Ctrl+Shift+1–9)⁠를 눌러요. 다음 날 새벽 4시가 되면 다시 모두 보여요.
  • 적을 때 #‘견적서 보내기 금요일까지 #회사’⁠처럼 적으면 회사 스페이스로 들어가요. ‘#⁠회’⁠나 초성 ‘#⁠ㅎㅅ’⁠만 적어도 알아들어요.
  • 옮기기와 관리할 일을 우클릭해 다른 스페이스로 옮겨요. 이름, 색, 순서는 책상 → 스페이스에서 정해요.
  • 만들지 않으면 그대로스페이스를 하나도 만들지 않으면 노트는 예전과 똑같아요. 한 스페이스만 보는 동안에도 다른 스페이스의 알림은 그대로 와요.

스페이스별로 묶기

회사, 집, 공부를 한눈에

오늘 할 일을 스페이스마다 모아 볼 수 있어요. 머리말의 ‘모든 스페이스 ▾’⁠에서 켜거나 ⌥⌘G(Windows는 Ctrl+Shift+G)⁠를 눌러요.

  • 메모지와 책갈피스페이스마다 작은 메모지 카드로 모으거나, 머리에 책갈피를 단 묶음으로 보여요. 모양은 책상 → 스페이스에서 골라요.
  • 넓히면 칸으로묶어 보는 동안은 노트를 가로 1,200px까지 넓힐 수 있어요. 자리가 넉넉하면 스페이스마다 한 칸씩 나란히 놓이고, 칸 아래 ‘+ 회사에 넣기’⁠로 바로 적어요.
  • 끌어서 옮기기할 일을 다른 묶음으로 끌어 놓으면 스페이스가 바뀌어요. ⌥⌘↑ ⌥⌘↓(Windows는 Ctrl+Alt+↑ Ctrl+Alt+↓)⁠로도 옮기고, 여러 개를 골라 한 번에 옮길 수도 있어요.
  • 반복 할 일도‘매일 물 마시기 #집’⁠처럼 적으면 날마다 생기는 할 일이 그 스페이스에 들어가요. 어디에도 넣지 않은 할 일은 ‘일반’⁠에 모여요.

자동 백업

하루 한 번, 저절로 백업해요

저장 폴더를 하루 한 번 백업 파일(.jongi)⁠로 남겨요. 가져오기나 되돌리기처럼 목록을 덮어쓰기 전에도 한 번 더 남겨요.

  • 저장과 백업을 한곳에책상 → 저장과 백업은 ‘할 일을 어디에 둘까요?’⁠로 시작하고, 마지막 백업이 언제였는지 한 줄로 알려 줘요. 백업 목록과 백업 파일 내보내기 · 가져오기는 ‘자세히 보기’⁠에 있어요.
  • 골라서 되돌려요백업 목록에서 하나를 고르면 ‘합치기’⁠와 ‘바꾸기’ 중에 골라요. 합치기는 지금 것을 두고 그 뒤에 지운 것만 되살려요. 어느 쪽이든 지금 것을 먼저 백업해 둬요.
  • 이 컴퓨터에만 있어요백업은 저장 폴더가 아니라 이 컴퓨터의 백업 폴더에 쌓여요. 공유 폴더를 써도 다른 기기로 가지 않아요. 매일 백업은 14개까지 남아요.
  • 폴더를 옮길 때도다른 저장 폴더를 고르면 지금 목록이 그 폴더로 옮겨진다고 미리 알려 줘요. 덮어써도 덮어쓰기 전 목록을 백업해 둬요.

메모 서랍

메모는 화면 끝 서랍에

어떤 앱을 쓰다가도 화면 끝에서 서랍을 꺼내 메모를 보고, 바로 적고, 그 자리에서 고쳐요. 예전 노트의 메모 탭에 쓴 메모는 서랍의 ‘메모’ 폴더에 그대로 있어요.

  • 어디서든 꺼내요⇧⌘D(Windows는 Ctrl+Shift+D)⁠를 누르거나 화면 끝의 고양이 발 손잡이를 눌러요. 다른 앱을 눌러도 서랍은 닫히지 않아요.
  • 폴더는 옆 책갈피책갈피 하나가 폴더 하나예요. 메모는 고정, 오늘, 어제, 지난주, 달별로 묶여 보이고, 링크나 전화번호가 있으면 카드에 작게 표시돼요.
  • 우클릭으로 정리해요메모, 책갈피, 서랍 빈 곳마다 메뉴가 있어요. 폴더로 옮기기, 복제, 정렬을 여기서 하고, 메모 한 장만 다른 종이로 바꿀 수도 있어요.
  • 종이와 바탕종이는 노트와 같은 열다섯 가지예요. 바탕은 불투명이 기본이고 반투명, 투명, 바탕 없음도 골라요. Windows의 반투명은 아직 실제 PC에서 보지 못했어요.

메모 서랍

서랍이 넓어지고 찾기 쉬워졌어요

1.46(Windows 1.31)⁠에서 메모 서랍을 많이 다듬었어요. 크게 보면 서랍이 화면 쪽으로 넓어지고, 아래 줄에 글자 수가 보여요.

  • 폴더별로 찾기찾은 메모가 폴더마다 묶여요. ‘안 한 체크’, ‘링크’, ‘고정’ 칩으로 거르고, 지금 폴더에서만 찾을 수도 있어요.
  • 제목만폴더 이름 ▾(⌘L, Windows는 Ctrl+L)⁠에서 ‘제목만’⁠을 고르면 메모가 제목 한 줄씩 보여요. 정렬도 여기서 고르고, 고른 보기는 폴더마다 기억해요.
  • 지운 메모 30일지운 메모는 30일 동안 남아요. 폴더 이름 ▾ 메뉴의 ‘지운 메모’⁠에서 원래 폴더로 되돌려요.
  • 체크 상자와 링크 칸메모를 고치는 동안에도 체크 상자가 보이고, 상자가 커져서 누르기 쉬워요. 글을 고르고 ⌘K(Windows는 Ctrl+K)⁠를 누르면 메모 아래에 링크 칸이 떠요.

메모 글꼴

메모 글꼴과 간격을 골라요

책상 → 메모 서랍의 ‘메모 글꼴’⁠에서 글꼴, 코드 글꼴, 글자 크기, 줄 간격, 문단 간격을 골라요. 서랍의 모든 메모와 카드에 같이 써요.

  • 노트와 같은 모양노트와 메모 서랍의 글꼴 설정이 같은 모양이라, 한쪽에서 익히면 다른 쪽도 똑같이 써요.
  • 코드 글꼴코드 글꼴로 D2Coding을 고를 수 있어요. 한글 한 글자가 영문 두 글자 폭이라 코드 줄의 칸이 맞아요.
  • 쓰는 그대로 보여요굵게, 제목, 목록, 체크, 코드가 쓰는 그대로 그 모양으로 보여요. 펼친 메모의 서식(Aa) 단추나 ⌘B 같은 키로 바꿔요.
  • 체크 목록 칩메모 카드에서 체크 목록이 얼마나 끝났는지 ‘2/4’ 칩 안의 막대로 보여요.

그 밖에

이번에 함께 달라진 것

Mac 1.49 · Windows 1.34에서 노트, 위젯, 속도, Claude 연결도 손봤어요.

  • 노트를 바탕화면에 펴 둬요노트 위쪽 핀에서 보통 · 항상 위에 두기 · 바탕화면에 두기 가운데 골라요. 바탕화면에 두면 노트가 위젯처럼 늘 다른 창 뒤에 있고, 단축키로 열 때만 잠깐 앞으로 와요.
  • 마우스를 움직여도 조용해요Mac에서 다른 앱을 쓰며 마우스를 움직여도 종이냥이 거의 깨지 않아요. 마우스가 고양이와 위젯에서 멀면 1초에 몇 번만 위치를 봐요.
  • Windows 위젯도 바탕화면에‘항상 위에 두기’⁠를 끈 위젯은 눌러도 다른 창 위로 올라오지 않아요. Mac처럼 바탕화면에 머물러요.
  • 새 Claude Code 연결 명령Windows의 Claude Code 연결 명령이 종이냥 실행 파일로 돌아가요. 다른 프로그램이 종이냥 실행 파일을 Node처럼 쓸 수 없게 막았어요. 예전에 복사해 둔 명령도 그대로 돼요.

두 번 만들고, 같게 지켰어요

Mac은 Swift(SwiftUI + AppKit), Windows는 Electron + TypeScript로 따로 만들었어요. 코드는 나누지 않고, 두 앱이 같은 시험 사례 표를 통과하게 해서 동작을 맞춰요.

질문

자주 묻는 것

정말 무료예요?

네. 결제도, 잠긴 기능도 없어요. 소스 코드는 GitHub에 Apache License 2.0으로 공개돼 있어요.

계정이 필요해요? 내 기록은 어디에 있어요?

계정도 서버도 없어요. 처음에는 이 컴퓨터 안의 종이냥 폴더에, 원하면 내가 고른 폴더에 파일로 저장돼요. 폴더는 책상 → 저장과 백업에서 바꿔요. 자세한 건 개인정보 안내에 있어요.

Mac과 Windows에서 같이 쓸 수 있어요?

네. 두 컴퓨터에서 같은 공유 폴더(iCloud Drive, OneDrive, Dropbox 등)⁠를 저장 위치로 고르면 돼요. 기기마다 보일 스페이스도 따로 정할 수 있어요.

Google 캘린더와 연결돼요?

아니요. 다섯 버전에 걸쳐 만들었고 잘 동작했지만 뺐어요. 업무 일정이 개인 공간에 섞이는 게 싫었고, 같이 써 본 사람들도 같은 이야기를 했어요. 자세한 이유는 결정 기록에 적었어요.

처음 열 때 왜 막혀요?

코드 서명을 하지 않은 빌드라서 그래요. Mac은 응용 프로그램 폴더에서 우클릭 → 열기를 누르고, 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 눌러요. Windows는 SmartScreen 창에서 추가 정보 → 실행을 눌러요.

어떤 언어와 환경에서 돼요?

한국어, 영어, 네덜란드어를 지원해요. Mac은 macOS 14 이상의 Apple Silicon, Windows는 10/11 x64에서 돌아가요. 다만 Windows 버전은 macOS 위 Electron에서만 확인했고, 실제 Windows PC에서는 아직 시험하지 못했어요.

받은 파일 확인

릴리스마다 파일의 SHA-256 값을 파일 확인값(SHA256SUMS)⁠과 릴리스 노트에 적어 둬요. 받은 파일의 값이 같으면 올린 그대로예요. 값이 다르면 열지 말고 지워 주세요.

  • Mac 터미널: shasum -a 256 ~/Downloads/JongiNyang-1.49.0.dmg
  • Windows PowerShell: Get-FileHash "$HOME\Downloads\JongiNyang-1.34.0-x64.exe" -Algorithm SHA256
