# 종이냥 글쓰기 가이드

앱 화면, 도움말, 사이트, README, 릴리스 노트에 들어가는 글의 기준이에요. 새 문구를 쓰거나 고칠 때 이 문서를 보고, 내보내기 전에 맨 아래 점검표를 한 번 돌려요.

- 출발점: 토스의 [「토스의 8가지 라이팅 원칙들」](https://toss.tech/article/21022)(2022). 다섯 가치와 여덟 원칙을 종이냥에 맞게 고쳐 썼어요.
- 낱말은 [용어표](terms.md)를 따라요. 이 문서는 낱말이 아니라 문장을 다뤄요.
- 아래 예시의 ‘전’은 모두 문구 점검에서 찾은 우리 옛 문구예요.

## 목소리

종이냥은 **고양이가 앉아 있는 종이 노트**예요. 말투도 그래요.

- **해요체.** ‘~합니다’, ‘~하십시오’, ‘~하세요’로 시키지 않아요. 부탁은 ‘~해 주세요’, 권할 땐 ‘~해 볼까요?’.
- **차분하게.** 느낌표는 축하할 때만. 한 화면에 하나 넘지 않게.
- **정직하게.** 못 한 건 못 했다고, 모르는 건 모른다고 써요. 데이터가 어디로 가는지는 숨기지 않아요.
- **앱은 ‘종이냥’, 고양이는 ‘저’.** 설정 · 도움말 · 오류는 앱이 말해요(주어를 빼거나 ‘종이냥이’). 한마디 · 말풍선 · 처음 안내의 인사만 고양이가 ‘저’로 말해요.
- **공손하지만 높이지 않아요.** ‘알려 드려요’보다 ‘알려 줘요’. ‘오신 걸 환영해요’처럼 인사 한두 곳만 높여요.

## 다섯 가지 가치

| 가치 | 종이냥에서는 | 전 → 후 |
| --- | --- | --- |
| **분명하게** | 쓰는 사람이 한 번에 알아들어요. 만든 사람만 아는 말을 쓰지 않아요. | ‘그 목록 쓰기’ / ‘지금 목록으로 바꾸기’ → ‘폴더 목록 쓰기’ / ‘이 Mac 목록으로 덮어쓰기’ |
| **짧게** | 훑어봐도 읽혀요. 꼭 필요한 말만. | 저장 폴더 각주 3줄(파일 이름 다섯 개) → ‘할 일 · 메모 · 일정 · 기록이 모두 이 폴더에 있어요.’ + 자세히 |
| **편하게** | 기술 말과 딱딱한 말을 쉬운 말로. | ‘AI 연결 파일을 쓰지 못했어요.’ → ‘AI 연결 설정을 저장하지 못했어요.’ |
| **정직하게** | 대가를 숨기지 않고, 부풀리지 않아요. 조금 손해여도 사실대로. | (AI 연결 칸에 없음) → ‘Claude가 읽은 내용은 대화와 함께 Claude로 가요.’ |
| **마음을 담아** | 사실만으로 모자란 순간엔 한마디 더. | ‘메모를 저장하지 못했어요.’ → ‘메모를 저장하지 못했어요. 앱을 끄기 전까지 적은 글은 화면에 그대로 있어요.’ |

## 여덟 가지 점검

글마다 아래 여덟 질문을 던져요. 예시는 모두 우리 문구예요.

**1. 다음에 무슨 일이 생길지 알려 주나요?** — 버튼과 제목이 결과를 미리 말해요.
- 저장 오류의 ‘확인’ → ‘닫기’ (옆 버튼 ‘저장 폴더 열기’와 짝이 맞게)
- 좋은 예: 언어를 바꿀 때 ‘바꾸고 다시 시작’

**2. 문장 안에 군더더기가 없나요?** — 빼도 뜻이 같은 말은 빼요.
- ‘전에 쓰던 목록을 읽지 못했어요. … 새 목록은 그대로 잘 저장돼요.’ → ‘목록 파일을 읽지 못해서 빈 목록으로 시작했어요. …’
- ‘알림 · 반복 · 마감 설정’ → ‘알림 · 반복 · 마감’

**3. 한 화면에 같은 말이 두 번 있지 않나요?**
- 빈 노트: 고양이 아래 ‘오늘 할 일을 한 줄 적어 볼까요?’와 아래줄 ‘오늘 한 장, 가볍게 시작해요’ → 앞의 것 하나만
- 빈 메모 폴더: 가운데 안내와 아래 ‘공부에 아직 메모가 없어요’ → 아래는 ‘비어 있어요’

**4. 지금 필요한 것만 말하나요?** — 바로 위에 보이는 것, 이미 아는 것은 다시 말하지 않아요.
- 완료한 일 각주 ‘… 기록은 책상 → 완료 기록에서 볼 수 있어요.’ → 바로 위 행이 ‘완료 기록 보기’라 빼요.

**5. 소리 내어 읽어도 자연스럽나요?** — 한 문장에 한 가지. 어려운 말 대신 쉬운 말.
- AI 스위치 각주(보고 · 넣고 · 보여 주고 · 받으면 고치고 · 못 지우고 · 끄면 못 읽고, 한 문단) → 세 문장으로: 무엇을 하나 / 무엇을 안 하나 / 무엇이 Claude로 가나
- ‘켜 두면 다른 앱의 같은 단축키보다 먼저 받아요’ → ‘다른 앱이 같은 키를 써도 서랍이 먼저 열려요’

**6. 강요하지 않고 권하나요?** — 겁주거나 재촉하지 않아요.
- 한마디 ‘서둘러요! 제가 응원할게요.’ → ‘하나씩 챙겨요. 응원할게요.’
- 한마디 ‘밥 먹고 하는 거예요. 꼭이요!’ → ‘밥 먹고 해요. 할 일은 기다려 줘요.’

**7. 누구나 아는 말인가요?** — 유행어, 상표, 개발자 말은 빼요.
- ‘깃허브처럼 … 초록 잔디’ → ‘날마다 끝낸 개수를 초록 칸으로’
- ‘오후 햇볕은 낮잠 각이에요’ → ‘오후 햇볕엔 낮잠이 솔솔 와요’

**8. 숨은 마음을 읽었나요?** — 기쁜 순간, 불안한 순간에 한마디.
- 저녁 정리: ‘오늘 4개 남았어요. 내일로 넘길까요?’ → ‘오늘도 수고했어요. 남은 4개는 내일로 넘길까요?’
- 좋은 예: 다 끝낸 노트의 ‘오늘 한 장 끝! 수고했어요’, 쉰 날의 ‘이 날은 쉬어 갔어요.’

## 우리만의 규칙

### 버튼

- **동사로 끝내요.** ‘지우기’, ‘되돌리기’, ‘내일 하기’처럼 ‘-기’, 또는 ‘내일로’, ‘언젠가로’처럼 가는 곳. ‘끝냄’, ‘마침’처럼 상태를 말하는 명사는 버튼에 쓰지 않아요.
- 할 일에 이름이 있으면 ‘확인’ · ‘예’ 대신 그 이름을 써요. 지우거나 덮어쓰는 버튼은 그 동사를 그대로(‘지우기’, ‘덮어쓰기’).
- 두 버튼을 ‘그’ · ‘지금’ · ‘이것’으로 가르지 않아요. 무엇이 남고 무엇이 사라지는지 이름에 넣어요.
- 기본 버튼은 오른쪽, Enter가 먹으면 ↩ 표시. 취소는 ‘취소’.

### 아래 안내(토스트)

- 틀: **‘[무엇을] [어떻게] 했어요 · 되돌리기’**. 예: ‘내일로 옮겼어요 · 되돌리기’, ‘3개 끝냈어요 · 되돌리기’, ‘‘회사’로 옮겼어요’.
- 한 줄, 과거형. 대상이 뻔하면 빼고(‘지웠어요’), 헷갈리면 넣어요(‘스페이스 ‘회사’를 지웠어요’).
- 곳 이름은 화면 이름 그대로: ‘기록으로’가 아니라 ‘완료 기록으로’.
- 실패: ‘[무엇을] 하지 못했어요’ + 이유 한 마디. 사용자가 지킨 걸 지켰다면 그렇게 말해요(‘그사이 고친 항목이라 그대로 뒀어요’).

### 확인 쪽지

- **제목**: ‘~할까요?’로 무엇을 하는지. 예: ‘지금 것을 이 백업으로 바꿀까요?’
- **본문**: ① 무엇이 바뀌는지 ② 되돌릴 수 있는지, 백업이 어디 남는지. 두 줄 안.
- **버튼**: 제목의 동사 그대로 + ‘취소’.
- 좋은 예: ‘집중을 그만둘까요?’ / ‘지금까지 집중한 시간은 기록에 남아요.’ / ‘그만두기’ · ‘계속하기’

### 오류

- 틀: **무엇을 못 했나 → 지금 상태(안심) → 할 일**. 예: ‘가져오지 못했어요. 지금 목록은 그대로예요.’
- 탓하지 않아요(‘잘못 입력했어요’ ✕). 오류 번호, 영어 원문, 긴 경로를 붙이지 않아요. 경로는 폴더 이름 + ‘폴더 열기’ 버튼.
- 할 일이 없으면 지어내지 않아요. 대신 무엇이 지켜졌는지 말해요.
- 입력을 알아듣지 못하면 예시를 하나 줘요: ‘알람 시간을 알아듣지 못했어요. ‘알람 7시’처럼 적어 보세요.’

### 빈 상태

- 한 화면에 하나. **여기에 무엇이 오는지 + 어떻게 넣는지(예시 하나)**.
- 고양이 그림이 있으면 고양이 아래 한 줄. 아래줄 · 머리말은 숫자만(‘비어 있어요’).
- 찾기 결과 없음은 한 틀: ‘‘{찾은 말}’에 맞는 게 없어요’ + 할 수 있는 다음 것(‘모든 폴더에서 찾기’).

### 숫자와 단위

- 숫자와 단위는 붙여요: ‘30분’, ‘3개’, ‘4일째’. 큰 숫자 + 작은 단위로 그린 자리(남은 시간 고리, 완료 기록 카드)만 디자인으로 띄워요.
- 시간 범위는 en dash: ‘13:00–14:00’.
- 남은 시간은 올려서 보여 줘요(30분이 ‘29분’으로 보이지 않게). ‘1:01 뒤’처럼 시각과 헷갈리는 꼴은 쓰지 않아요.
- 개수 세기: 할 일 · 일정은 ‘개’, 메모는 ‘장’, 집중은 ‘번’.
- ‘약’은 정말 대략일 때만(‘약 45분마다’).

### 기술 용어 · 파일 · 경로

### 종이냥 한마디(말풍선)

- 한두 줄, 줄마다 짧게. 고양이는 ‘저’, 해요체.
- **응원하고 쉬게 해 주는 말.** 재촉 · 꾸중 · 죄책감(‘밀린 일’, ‘서둘러요’, ‘꼭이요!’)은 쓰지 않아요. 밀린 일은 ‘괜찮아요’로 시작해요.
- 상표(츄르), 유행어(각, 화이팅), 점수 매기기(백 점)는 빼요. 고양이다운 말(냥, 골골, 꾹꾹)은 좋아요.
- 질문에는 솔직한 답 둘을 줘요(‘좋아요’ / ‘나중에요’). 어느 답에도 기분 상하지 않게 대답해요.
- 사실이 아닌 걸 말하지 않아요. 고양이가 하지 않은 일(저장, 동기화)을 했다고 하지 않아요.
- 줄은 `mac/scripts/chatter/chatter_lines.py` 한 곳에서 ko · en · nl을 같이 고쳐요.

### English · Nederlands

- **같은 뜻, 그 말답게.** 한국어 어순을 옮기지 않아요. 짧은 쪽을 골라요.
- 낱말은 `windows/src/i18n/en.ts` 머리의 용어표와 [용어표](terms.md)를 따라요. en ‘to-do’(task ✕), nl ‘taak’. 화면 이름은 앱과 사이트가 같게(‘notepad’, ‘Day ribbon’).
- en: sentence case, ‘Couldn’t …’로 시작하는 오류, Mac ⌘ / Windows Ctrl.
- nl: ‘je’로 말하고, 오류는 ‘Het lukte niet om …’처럼 온전한 문장으로. nl은 ko보다 30% 남짓 길어요. 렌더해서 잘림을 봐요.
- 번역은 아직 원어민이 본 적이 없어요. 큰 문구를 바꾸면 원어민 확인 목록에 올려요.

### 예시 데이터

- 예시는 지어낸 것만: 회사 · 집 · 공부, ‘보고서 쓰기’, ‘팀 회의’, 010-1234-5678.
- 실제 메모, 이름, 회사, 전화번호, 로컬 경로를 문서 · 이슈 · 스크린숏에 쓰지 않아요. 스크린숏에서 글을 옮기지 않아요. 올리기 전에 그림 속 글자를 한 번 읽어 봐요.

## 내보내기 전 점검표

- [ ] 버튼이 동사이고, 누르면 무엇이 되는지 이름만 봐도 알아요.
- [ ] 한 문장에 한 가지. 소리 내어 읽어 봤어요.
- [ ] 같은 화면에 같은 말이 두 번 없어요(빈 상태, 각주, 제목과 행 이름).
- [ ] 바로 위 · 옆에 보이는 걸 다시 설명하지 않아요.
- [ ] 각주는 한 줄(많아야 두 줄), 나머지는 ‘자세히’로.
- [ ] 오류는 무엇을 못 했나 + 지금 상태 + 할 일이 있어요.
- [ ] 확인 쪽지는 무엇이 바뀌는지와 되돌릴 수 있는지를 말해요.
- [ ] 파일 이름 · 경로 · 개발자 말이 설정과 오류에 없어요.
- [ ] 데이터가 기기 밖으로 나가면 그 자리에서 말해요.
- [ ] 재촉 · 겁주기 · 유행어 · 상표가 없어요.
- [ ] 숫자와 단위가 붙어 있고, 시간 형식이 둘레와 같아요.
- [ ] 용어표의 낱말을 썼어요. en · nl도 같이 고쳤어요.
- [ ] ko · en · nl, 낮 · 밤으로 렌더해서 잘림과 줄 수를 봤어요.
- [ ] 예시는 지어낸 것이고, 개인 정보와 로컬 경로가 없어요.
