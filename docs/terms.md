# 용어표

같은 것은 두 앱(Mac · Windows)과 세 언어(ko · en · nl)에서 같은 말로 불러요. 새 메뉴나 문구를 쓸 때 이 표를 먼저 봐요. 바꾸면 이 표도 같이 고쳐요. 메뉴도 이 표를 따라요.

## 쪽지의 키 표시

- Enter(또는 ⌘↩ · Ctrl+↩)가 누르는 기본 버튼에는 버튼 안에 키 표시(↩)를 붙여요. 사용 안내의 ‘다음’ · ‘시작하기’도요.
- 키를 받지 않는 쪽지(할 일 알림, 저녁 정리)에는 붙이지 않아요. 다른 앱에서 타자를 치는 중에 떠도 키를 가져가지 않게 일부러 그래요.
- 지우기처럼 되돌리기 어려운 버튼은 Enter로 누르지 않고, 키 표시도 없어요(반복 일정의 ‘모두 지우기’).
