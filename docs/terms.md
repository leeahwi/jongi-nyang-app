# 용어표

같은 것은 두 앱(Mac · Windows)과 세 언어(ko · en · nl)에서 같은 말로 불러요. 앱 화면뿐 아니라 도움말 · 사이트 · README · 릴리스 노트도 이 표의 말을 써요. 새 메뉴나 문구를 쓸 때 이 표를 먼저 보고, 말을 바꾸면 이 표도 같이 고쳐요.

화면에 보이는 말만 정해요. 파일 이름, 저장하는 값, 코드 이름은 말이 바뀌어도 그대로 둬요(예: ‘낮 · 밤’의 저장 값).

## 쪽지의 버튼

- 채운 버튼은 쪽지마다 하나, 기본 버튼만이에요(오른쪽 끝). 나머지는 모두 같은 글자 버튼이에요. 저녁 정리 ‘내일로’, 아침 정리 ‘오늘 할게요’, 할 일 알림 ‘모두 끝내기’ · ‘끝내기’.
- 저녁 정리는 두 앱이 같은 구성이에요: 머리 ‘저녁 정리’, 질문 옆 고양이(펫 위에 뜰 때는 고양이 없이), ‘넘길 할 일 N’, 줄 끝 ‘어제부터’ · ‘N일째’, 그대로 두기 · 언젠가로 · 내일로.

## 쪽지의 키 표시

- Enter(또는 ⌘↩ · Ctrl+↩)가 누르는 기본 버튼에는 버튼 안에 키 표시(↩)를 붙여요. 사용 안내의 ‘다음’ · ‘시작하기’도요.
- 키를 받지 않는 쪽지(할 일 알림, 저녁 정리)에는 붙이지 않아요. 다른 앱에서 타자를 치는 중에 떠도 키를 가져가지 않게 일부러 그래요.
- 지우기처럼 되돌리기 어려운 버튼은 Enter로 누르지 않고, 키 표시도 없어요(반복 일정의 ‘모두 지우기’).
