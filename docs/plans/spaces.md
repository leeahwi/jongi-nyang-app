# 기획: 할 일 스페이스

> 상태: 기획 확정(2026-10-28), 구현 전. 시안은 [spaces-mock.png](spaces-mock.png)([html](spaces-mock.html))에 있어요.

## 1. 바라는 것

- **할 일**을 일의 갈래(A 업무, B 업무, 집 …)로 나누고 싶어요. 메모는 그대로예요. 메모는 1.43부터 메모 서랍의 폴더로 따로 나눠요.
- 그래도 **오늘 할 일을 한 장에서 다 보는 것**은 놓치고 싶지 않아요.

정리하면 **나누되 쪼개지 않기**예요. 스페이스는 표시와 잠깐 거르기로만 쓰고, 기본 화면은 한 장 그대로 둬요.

## 2. 사용자 결정 (2026-10-28)

| 질문 | 결정 |
| --- | --- |
| 무엇을 나누나 | **할 일만.** 메모 서랍의 폴더와는 따로예요 |
| 이름 | **스페이스** (메모의 ‘폴더’와 헷갈리지 않게) |
| 오늘 한 장의 기본 모양 | **섞어서, 줄 왼쪽 끝 색 띠만** (시안 ①). 스페이스별로 묶기는 설정에서 켜는 선택(④) |
| 한 스페이스만 보기 유지 | **다음 날 아침(4시 규칙)에 풀기** |
| 일정(캘린더) | **1단계에서는 넣지 않기** |

## 3. 다른 앱은 어떻게 하나

| 앱 | 나누는 방법 | 한곳에서 다 보기 |
| --- | --- | --- |
| Things 3 | Area(업무 · 집 · 건강) → 그 안의 Project | Today · Upcoming이 모든 Area의 할 일을 한 목록으로 모아요. 할 일은 프로젝트에 있으면서 Today에도 보여요 |
| Todoist | Project(+ Label). 빠른 입력에서 `#프로젝트` | Today 보기가 모든 프로젝트의 오늘 할 일을 모아요. 필터 `#Work`로 한 프로젝트만 |
| Apple 미리 알림 · Microsoft To Do | 목록(List) | ‘오늘’ · ‘나의 하루’가 모든 목록을 모아요 |
| macOS 집중 모드 필터 | 앱이 `SetFocusFilterIntent`로 ‘이 집중 모드에선 이것만’을 제공(macOS 13+) | 집중 모드를 끄면 모두 보여요 |
| Arc 브라우저 Spaces | 공간을 통째로 바꿔요 | 한곳에서 다 보기가 없어요. ‘한 장’과 맞지 않아요 |

공통점은 이래요.

1. 갈래는 항목의 속성이에요.
2. ‘오늘’은 늘 모든 갈래를 모아요.
3. 빠른 입력에 `#`를 써요.
4. 거르기는 잠깐이에요.

## 4. 화면별 동작 (시안 번호)

**① 오늘 한 장 (기본)**
- 모든 할 일이 지금처럼 한 장에 보여요(다음 · 그 밖에 그대로).
- 스페이스가 있는 할 일만 줄 왼쪽 끝에 그 색의 작은 띠가 붙어요. 마우스를 올리면 스페이스 이름이 보여요.
- 스페이스 없는 할 일은 지금과 똑같아요. 스페이스를 하나도 만들지 않은 사람에게는 아무것도 바뀌지 않아요. 이때는 `모든 스페이스 ▾`도 숨겨요.

**② 한 스페이스만 보기 (잠깐 거르기)**
- 머리말 `모든 스페이스 ▾` 또는 `⌘⌥1–9`로 골라요. `⌘⌥0`은 모두 보기예요.
- 위에 띠로 `회사만 보는 중 · 다른 할 일 4개는 숨겼어요 · 모두 보기`를 늘 보여 줘요.
- 이때 적는 할 일은 그 스페이스로 들어가요(입력 줄 안내도 `회사에 적어요`).
- 다음 날 아침(4시 규칙)에 모든 스페이스로 돌아와요. 노트를 접었다 펴도 유지돼요.
- 숨긴 할 일의 알림은 그대로 울려요. 거르기는 보기만 바꿔요.
- 하루 띠 · 하루 일정표의 할 일 블록도 같은 거르기를 따라요. 다른 스페이스의 할 일은 흐리게 보이고, 일정은 그대로예요.

**③ 입력 줄 `#스페이스`**
- `견적서 보내기 금요일까지 #회사` → 할 일 · 금요일 마감 · 회사.
- 칩에 스페이스가 보이고 `Tab`으로 바꿔요.
- 앞부분(`#회`)이나 초성(`#ㅎㅅ`)만 쳐도 돼요. 없는 이름이면 칩이 `새 스페이스 ‘회사’`가 되고, 넣을 때 만들어요.
- `#`가 붙은 일정 · 타이머 · 알람에는 스페이스를 붙이지 않고, `#회사`는 글에서 빼요.
- 빠른 입력 창(`⌃⌥N`)도 같아요. 지금 입력 해석에서 `#`는 쓰이지 않아요(확인함).

**④ 스페이스별로 묶기 (선택, 기본 꺼짐)**
- 켜면 한 장 안에서 ‘다음 · 그 밖에’ 대신 스페이스 머리말로 나눠요.
- 순서는 스페이스 순서이고, 맨 끝이 ‘스페이스 없음’이에요. 여전히 한 장, 스크롤 하나예요.

**⑤ 스페이스로 옮기기 · 관리**
- 할 일 줄 우클릭 → `스페이스로 옮기기 ▸`(목록, ✓ 지금 것, `스페이스 없음`, `+ 새 스페이스…`).
- 할 일을 고치는 쪽지(시트)에도 스페이스 칸을 둬요.
- 관리는 `모든 스페이스 ▾` 맨 아래 `스페이스 관리…` → 책상의 **스페이스** 칸에서 해요.
  - 만들기, 이름, 8색(메모 폴더와 같은 색 묶음), 끌어서 순서, 지우기(할 일은 ‘스페이스 없음’으로 가고 `되돌리기`가 떠요).

**그 밖의 화면**
- **앞으로 탭**: 같은 색 띠, ②의 거르기를 따라요.
- **메뉴 막대 오늘 창 · 집중 카드**: 색 띠, 스페이스 이름(작게).
- **검색 `⌘F`**: `#회사`로 그 스페이스의 할 일을 찾아요.
- **반복 할 일**: 반복 규칙(series)에 스페이스를 붙이면 새로 만들어지는 할 일도 그 스페이스예요.
- **완료 기록 · 집중 기록(책상)**: 스페이스로 거르기, 스페이스별 집중 시간(2단계).
- **종이냥 for Claude**: 도구에 `space` 인자(목록 · 추가 · 옮기기), `회사 할 일 보여 줘`(2단계).
- **macOS 집중 모드 필터(3단계)**: ‘업무’ 집중 모드면 자동으로 ‘회사만 보기’. Windows에는 해당 기능이 없어요.

## 5. 데이터 (두 앱 같은 형식)

- **`todos.json`은 모양을 바꾸지 않아요.** 옛 버전(Mac ≤ 1.44, Windows ≤ 1.29)이 저장할 때 모르는 키를 지울 수 있어요. Mac은 Codable이라 지워요. Windows는 구현 전에 확인해요. 메모 서랍처럼 따로 둬요.
- **새 파일 `todo-spaces.json`**

  ```json
  {
    "spaces": [{ "id": "…", "name": "회사", "color": "pink", "order": 0, "updatedAt": "…", "deleted": false }],
    "items":  { "<todo id>":   { "space": "…", "at": "…" } },
    "series": { "<series id>": { "space": "…", "at": "…" } }
  }
  ```

  - 합치기는 `memo-folders.json`과 같아요. 스페이스는 id로 합치고, 자리는 나중에 고친 쪽이 이겨요.
  - 지운 스페이스는 30일 동안 표시를 남겨요. 지운 스페이스를 가리키는 할 일은 ‘스페이스 없음’이에요.
  - 모르는 키는 그대로 남겨요(1.44 규칙). 읽지 못하는 파일은 옆에 남겨 두고 새로 시작해요.
- **옛 버전과 함께 쓸 때**:
  - 옛 버전이 만든 할 일은 ‘스페이스 없음’으로 보여요.
  - 옛 버전이 할 일을 지우면 남은 자리 기록은 다음 정리 때 사라져요.
  - 스페이스 정보가 깨지지는 않아요.
- **백업(.jongi)**: `todo-spaces.json`을 넣고, 가져오기 합치기도 같은 규칙이에요.
- **완료 기록(archive)**: 끝낸 할 일이 archive로 갈 때 스페이스 id를 같이 적어요. archive 줄(jsonl)에 키를 더해도 옛 버전이 읽는지 구현 전에 확인해요.
- **기기 설정**: 한 스페이스만 보기 상태와 그 날짜, 스페이스별로 묶기.

- S1 `#회사`
- S2 `#회`(앞부분)

- S5 `#`만 있을 때

- S7 거르기 중 입력 → 그 스페이스
- S8 `#집` + 거르기 회사 → `#집`이 이김

- S10 지운 스페이스의 할 일 → 없음
- S11 두 기기에서 다른 스페이스로 옮김 → 나중 것
- S12 옛 버전이 저장한 `todos.json`과 합치기
- S13 반복 규칙 → 새로 만든 할 일
- S14 백업 내보내기 · 가져오기

- …

**키보드**
- `⌘⌥1–9` · `⌘⌥0`(Windows `Ctrl+Alt+1–9` · `0`).
- 전역 단축키(`⌃⌥M · J · N`)와 겹치지 않는지, Windows `Ctrl+Alt+숫자`가 AltGr 배열과 부딪히지 않는지 구현 전에 확인해요.

**성능**
- 색 띠는 그리는 비용이 거의 없어요.
- 거르기는 목록을 한 번 거르는 일이에요.
- 할 일 수천 개에서도 열기 · 입력 지연이 지금과 같아야 해요. 메모 대량 측정(`docs/perf-memo-stress.md`)과 같은 방식으로 할 일 대량 측정 단계를 더해요.

## 7. 고르지 않은 안

- **메모 폴더를 할 일에도 같이 쓰기**: 처음 기획안이었어요. 사용자가 할 일만 나누고 싶다고 해서 접었어요.
- **공간 통째로 바꾸기(Arc식)**: 스페이스마다 노트가 따로라 ‘한 장에서 다 보기’가 사라져요.
- **태그(여러 개)**: 색 띠가 여러 개가 되고 거르기 규칙이 복잡해져요. 할 일 하나에 스페이스 하나로 시작해요.
- **오늘 탭을 스페이스별 탭으로 쪼개기**: 탭이 늘고 한 장이 깨져요.
