# 한 장 · 전체 디자인 개선

> 앱 이름이 ‘한 장’이던 1.5–1.10 무렵의 작업 기록이에요(공개 저장소에서는 날짜와 당시 스냅숏 이미지를 뺐어요). 지금의 디자인은 [디자인 과정](../../docs/design-process.md)에 있어요.

## 조사와 판단

공식 제품 페이지와 실제 제품 그림을 확인했어요.

- [Things 디자인과 기능](https://culturedcode.com/things/features/): 할 일을 가운데 두고, 보조 정보와 편집 기능은 필요한 자리에 둬요. [Today 화면](https://static.culturedcode.com/things/videos/2017-05-18-website-videos/2-today-mac.png)의 정렬과 제목 · 메타데이터 대비를 참고했어요.
- [Bear](https://bear.app/): 작업 내용이 중심인 차분한 화면이에요. [공식 Mac 화면](https://bear.app/images/home/hero_mac.jpg)의 절제된 도구와 여백을 참고했어요.
- [Bear 글꼴 설정](https://bear.app/faq/typography-options/): 글꼴 고르기를 작업 공간의 일부로 다뤄요. 한 장에서는 기존 세 글꼴을 실제 미리보기와 함께 설정에 보여 줘요.

제품을 베끼지 않고, 위 원칙을 작은 종이 메모장에 맞게 써요. 여러 목록이나 사이드바는 더하지 않아요.

## 구현 방향

**시각적 주제:** 따뜻한 백지, 또렷한 잉크, 은은한 종이 결 위에 작은 곰과 고양이가 함께 있는 개인 메모장이에요.

**정보 순서:** 날짜와 제목 → 할 일 → 알림 시각 → 완료 현황. 할 일은 고른 손글씨로, 조작과 시각 정보는 시스템 글꼴로 써요. 캐릭터와 글꼴은 설정에서 쉽게 바꿔요.

**움직임:** 완료하면 연필 선이 그어지고, 줄 위에 마우스를 올리면 아래에 도구가 보이고, 알림이 뜨면 캐릭터가 인사해요. 동작 줄이기 설정을 따라요. 도구가 나타나도 본문 위치와 폭은 바뀌지 않아요.

## 바꾸는 것과 지키는 것

종이의 강한 얼룩 대비를 낮추고 공통 색과 버튼을 정리해요. 메인 머리, 줄 간격, 보조 정보, 아래 완료 표시, 설정과 알림 편집, 팝업을 함께 다듬어요. 저장, 실행 취소, 알림 일정, 세 가지 알림 디자인, 포스트잇 접기는 그대로 두고, 포스트잇 위치만 아래 사용자 의견대로 누른 자리로 고쳤어요. 외부 의존성은 더하지 않아요.

## 마지막 결과와 확인

- 메인: 머리 132pt, 목록은 44pt 한 줄 격자예요. 오른쪽에 시간표와 ⋯ 메뉴, 왼쪽에 끌기 손잡이가 있어요. 20pt 체크 상자와 완료 진행 표시가 있어요.
- 종이 결을 옅게 하고 잉크 대비를 높였어요. 곰 · 고양이와 세 가지 글꼴은 그대로예요.
- 설정: 꾸미기 · 알림 탭이에요. 같은 문장으로 글꼴을 비교하고, 알림 탭 아래 버튼은 고정했어요.
- 알림: 내용 길이에 맞는 높이, 정확한 시각, 바로 완료 · 미루기 · 노트 보기가 있어요. 아주 오래된 알림을 ‘몇천 분’으로 보여 주지 않아요.
- 메뉴 막대: 캐릭터 옆에 남은 수가 보이고, 모두 끝내면 체크가 보여요. 화면 읽기 설명도 같은 상태를 알려 줘요.
- 겹치던 버튼 스타일을 공통 PaperActionButtonStyle 하나로 합쳤고, 외부 의존성은 더하지 않았어요.

### 화면

## 한 줄 목록 보정

사용자 의견대로 모든 줄을 44pt 한 줄로 맞췄어요. 따로 있던 보조 정보 줄과 마우스를 올렸을 때의 도구 영역을 지우고, 알림은 오른쪽 시간표(오늘 · 내일 · 날짜 + 24시간 시각)로, 편집은 늘 보이는 ⋯ 메뉴로 모았어요. 작은 창에서 긴 제목은 말줄임하고, 마우스 도움말과 편집에서 전체를 볼 수 있어요.

바꾼 파일: PaperView.swift, PaperTheme.swift, ReminderTimeText.swift와 시각 형식 검사. 시각 검사에 오늘 · 내일 · 다른 날짜 · 다른 해 네 사례를 더했어요.

## 누른 자리에 접기 · 끌기 손잡이 · 날짜 표시

- 사용자가 원한 것: 모니터 위쪽 가운데가 아니라, 노트 위쪽을 두 번 누른 자리에 포스트잇 아이콘이 생겨야 해요.
- 시각적 주제: 백지와 한 줄 목록은 그대로 두고, 월 · 일 · 요일을 작은 달력 인쇄처럼 짜요.
- 정보 순서: 달력 날짜 → 오늘 할 일 → 캐릭터. 월과 요일은 작게, 날짜는 크게 나눠요.
- 움직임: 왼쪽 점 여섯 개 손잡이로 바로 끌어요. 놓을 줄의 위 · 아래 절반에 따라 끼워 넣을 선을 보이고, 놓을 때 한 번만 순서를 저장해요. ⋯ 메뉴는 편집용으로 남겨요.
- [Things 공식 디자인 · 목록 편집](https://culturedcode.com/things/features/)의 분명한 제목 위계와 바로 순서 옮기기, [Bear 글꼴 설정](https://bear.app/faq/typography-options/)의 읽기 좋은 여백을 참고했어요. 작은 달력 짜임은 이 앱을 위해 새로 설계했어요.

- 구현 파일: PaperView.swift(날짜 · 끼워 넣을 선), PaperTaskDragHandle.swift(네이티브 끌기 손잡이), AppModel.swift(앞 · 뒤에 끼워 넣기), PaperTodoApp.swift와 FloatingMascotPanel.swift(누른 좌표에 놓기).
- 메뉴와 끌기 동작을 나눴고, 창 배경으로 창을 옮기는 건 위쪽에서만 되게 했어요. 외부 의존성은 더하지 않았어요.
- 회귀 검사 66개: 코어 17 + 주기 13 + 개별 알림 13 + 시각 13 + 화면 6 + 위치 계산 4.
- 실제로 위쪽을 두 번 눌렀을 때: 요청 좌표 (860,874), 아이콘 가운데 (860,874), 오차 (0,0)이에요.
- 손잡이의 손쉬운 사용 동작으로 순서 바꾸기와 파일 저장을 확인했어요. 자동화 도구의 포인터 끌기로는 옮기기가 재현되지 않아서, 마우스 끌기 전체 경로는 확인을 마쳤다고 보지 않아요.

## 아래쪽 리마인더 다시 설계

시각적 주제: 화면 위에 잠깐 찾아온 작은 친구와 말풍선 하나예요. 무거운 종이 패널, 접힌 모서리, 동그란 캐릭터 받침과 세 버튼 줄을 지워요.

정보 순서: 예약 시각이나 남은 개수 → 실제 할 일 → 다시 알림. 완료는 체크로, 노트 열기는 제목으로, 미루기는 아래 묶음 하나로 나눠요. 고른 글꼴과 캐릭터는 그대로예요.

움직임: 작게 나타나는 움직임과 몇 번만 하는 손 인사, 마우스를 올리는 동안 자동으로 닫히지 않기. 완료 · 미루기 · 미리보기의 안전장치와 동작 줄이기는 그대로 지켜요.

정리 계획: 겹치던 세 레이아웃과 쓰지 않는 종이 · 말풍선 도형 · 버튼 스타일을 공통 말풍선 짜임으로 바꿔요. 저장된 세 스타일 값은 그대로 두고 미니 · 쪽지 · 친구로 다시 읽어요. 일정 · 저장 · 미리보기 콜백은 바꾸지 않아요.

## 1.10 참고 사례

공식 문서와 제품 페이지를 확인했어요. 페이지 글로만 확인했고, 화면 그림은 비교하지 않았어요.

- [Apple HIG · Notifications](https://developer.apple.com/design/human-interface-guidelines/notifications): 같은 주제로 알림을 여러 번 보내지 말고, 동작은 적고 짧게. → 할 일마다 뜨던 알림을 말풍선 하나로 합쳤어요.
- [UNNotificationCategory 요약 형식](https://developer.apple.com/documentation/usernotifications/unnotificationcategory): 묶인 알림은 개수 요약으로. → ‘외 N개’.
- [Apple HIG · Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers): 내용만큼만 크게. → 줄 수에 맞춰 말풍선 높이를 계산해요.
- [Things 3](https://culturedcode.com/things/features/): 보조 정보는 필요할 때만. → 손잡이는 마우스를 올릴 때 보이고, ⋯는 흐리게.
- [Todoist Today](https://todoist.com/help/articles/plan-your-day-with-the-todoist-today-view-UVUXaiSs): 동그라미로 바로 완료, 다 끝낸 화면에 따뜻한 한마디. → 말풍선 줄마다 완료, ‘오늘 한 장 끝!’.
- [DockCat](https://github.com/Auwuua/DockCat), [Finch](https://screensdesign.com/showcase/finch-self-care-pet): 재촉하지 않는 다정한 말투. → ‘아직 N개 남았어요’, ‘다 끝냈어요, 수고했어요!’.

확인한 것: 화면 검사 14개(묶음 말풍선, 동시에 울릴 개별 알림 3개 → 한 번만 표시)를 포함해 회귀 검사 74개와 warnings-as-errors 디버그 · 릴리스 빌드가 통과했어요.
